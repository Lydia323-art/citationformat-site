# Visual Style Brief

项目：apa-citation-generator
阶段：02-product
状态：NEEDS_REVIEW

## Product Feel

Quiet, academic, fast, and trustworthy. This is a student utility, not a marketing landing page.

## UI Priorities

- Tool first screen.
- No oversized decorative hero.
- Dense but clear form layout.
- Results visible without scrolling too far on desktop.
- Mobile flow must stay simple: input -> generate -> copy.
- Use restrained color with strong readability.

## Suggested Layout

- Top nav with compact brand and route links.
- Main tool area immediately under H1.
- DOI input as primary path.
- Manual form as secondary path.
- Output panel next to or below form.
- FAQ and guide sections after the tool.

## Competitor Structure Reference

- Use Scribbr as the main information-architecture reference: H1, short trust line, citation input, cite action, manual fallback, then APA guide content.
- Use Grammarly as the manual form / live preview reference: structured contributor fields and preview/copy area.
- Use MyBib as the plain-language education reference: what it is, who uses it, why use it, how to use it.
- Use QuillBot only for the top utility pattern; do not copy the PDF upload path because MVP forbids PDF upload.
- See `competitor-ui-reference.md` for the full breakdown.

## Tone

- Clear.
- Practical.
- Student-friendly.
- Avoid pretending to be official APA, ScienceDirect, MyBib, Scribbr, or Crossref.

## Components Needed

- Source type tabs.
- DOI input.
- Manual form fields.
- Generate button.
- Copy buttons.
- Warning banner.
- Error state.
- Example citation card.
- FAQ accordion.
- Footer legal links.
